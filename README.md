## Project Description
### Domain
Productivity
### Description
An application that allows you to see and control what goes on in your computer from a low level. 
Think of it as a combination of Task Manager, Docker Desktop, Windows Resource Monitor and a live error viewer. 
You can view hardware usage, manage docker containers, monitor network port usage and view logs.
---
## User Stories
### User Story 1
As a developer, I want to monitor my computer's CPU, RAM, and disk usage in real time, so that I can identify performance issues before they affect my work.
### User Story 2
As a developer, I want to view and control my Docker containers through a graphical interface, so that I can manage my development environment without typing terminal commands.
### User Story 3
As a network administrator, I want to identify which applications are using specific network ports, so that I can resolve port conflicts when running local servers.
### User Story 4
As a developer, I want to view application logs in real time and highlight errors, 
so that I can quickly identify and troubleshoot problems without manually opening log files.
---
## Use Cases
### Use Case 1
1. User opens the app
2. User navigates to the system monitoring dashboard
3. App displays CPU, RAM, disk for the appropriate operating system
4. If the resource usage is too high, the system alerts the user. 
### Use Case 2
1. User opens the app
2. User navigates to the Docker container dashboard
3. App displays all Docker containers available and their status
4. User can run and stop any container. 
### Use Case 3
1. User opens the app
2. User navigates to the network dashboard
3. App displays which applications are using which network ports
4. User can terminate processes using specific ports. 
### Use Case 4
1. User opens the app
2. User navigates to the logs dashboard.
3. User can drag any log files into the viewer
4. App shows the log files updating in real time.
